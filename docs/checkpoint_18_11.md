## 2. Ручной сбор данных

### SMS Spam: 100 реальных сообщений

| Класс | Кол-во | Источник | Лицензия |
|---|---|---|---|
| spam | 50 | [SMS Phishing Dataset](https://data.mendeley.com/datasets/f45bkkt8pr/1) (Mishra & Soni, 2022), метки spam и smishing | CC BY 4.0 |
| ham | 50 | [NUS SMS Corpus](https://github.com/kite1988/nus-sms-corpus) (Chen & Kan, 2013), английская часть | для исследований с цитированием |

Правила отбора:
- только английский язык, длина 20–300 символов, без испорченных символов;
- в ham нет e-mail и длинных номеров (персональные данные);
- сообщения нет в исходном SMS Spam Collection: проверялись точные копии, почти-копии
  (похожесть ≥ 0,9) и обрезанные версии (≥ 60 % общих словесных 3-грамм);
- отбор случайный, seed фиксирован, поэтому результат воспроизводим.

Для каждого источника в реестре указаны URL, дата обращения и лицензия.

### Clotho: 25 реальных аудиозаписей

- **Откуда:** вручную подобраны на [Freesound](https://freesound.org), откуда взят и сам Clotho.
- **Лицензия:** все 25 записей — CC0 1.0.
- **Длительность:** 15–30 с, как в Clotho.
- **Разнообразие:** 6 категорий источников звука — природа, животные, люди, транспорт, механизмы, быт.
- **Проверка на дубли:** ни одной записи нет в Clotho (сверка по `sound_id` с метаданными всех трёх частей датасета).

## 3. Разметка

**Инструмент:** Label Studio. Конфигурации интерфейса:
[SMS](https://github.com/Bezriska/DS-course-work/blob/main/labeling/label_studio/sms_spam.xml),
[Clotho](https://github.com/Bezriska/DS-course-work/blob/main/labeling/label_studio/clotho_captioning.xml).

**Процедура:**
1. Каждый аннотатор размечает все объекты в своей установке Label Studio и не видит чужие ответы.
2. Метки источника аннотаторам не показываются.
3. Label Studio сам фиксирует время разметки каждого объекта.
4. Согласие считается по двум выгрузкам: процент совпадений и Cohen's κ.
5. Расхождения разбираются вдвоём, итоговая метка опирается на правила codebook.

### SMS Spam: результаты

| Показатель | Значение |
|---|---|
| Размечено двумя аннотаторами | 100 сообщений |
| Процент согласия | **94 %** (94 из 100) |
| Cohen's κ | **0,88** — почти полное согласие по шкале Landis & Koch |
| Время разметки | Максим — 8,6 мин (медиана 4,3 с на сообщение), Виталий — 4,2 мин (медиана 1,3 с) |
| Расхождения | 6: m034, m036, m065, m086, m090, m095 |
| Итоговые метки | 52 ham, 48 spam |
| Совпадение итоговых меток с меткой источника | 98 из 100 (smishing считается за spam) |

Матрица совпадений (строки — Максим, столбцы — Виталий):

| | ham | spam |
|---|---|---|
| **ham** | 50 | 3 |
| **spam** | 3 | 44 |

Разбор расхождений. Решение по каждому записано вместе с правилом codebook.
- **m034, m036, m086 — фишинг под видом уведомления от банка** (поддельная ссылка или просьба
  позвонить под угрозой блокировки). Итог: spam. Расхождение одного типа в трёх сообщениях показало,
  что правило 3 сформулировано нечётко. В codebook версии 1.0 оно уточнено.
- **m095** — непрошеный призыв срочно позвонить на номер. Итог: spam.
- **m090** — личная переписка, метка spam была ошибкой. Итог: ham.
- **m065** — служебный код без ссылки и без просьбы о деньгах. Итог: ham. Для таких случаев
  добавлено правило 10. Здесь мы осознанно расходимся с меткой источника.

### Clotho: текущее состояние

На каждую запись Виталий написал 2 подписи на английском и заполнил 3 категориальных поля:
источник звука, место записи, наличие речи. Медиана времени — около 41 с на запись.
Вторая независимая разметка (Максим) в работе.

Согласие по Clotho будет считаться так:
- по категориальным полям — процент согласия и Cohen's κ;
- по подписям — сходство формулировок двух аннотаторов.

## 7. Использование ИИ

В работе использовалась LLM Claude (Anthropic). ИИ помогал:
- найти открытые датасеты для ручного сбора и проверить их лицензии;
- написать скрипты по текстовому описанию задачи: отбор SMS, проверка дубликатов,
  скачивание записей Freesound, подсчёт согласия, сборка итоговых меток.
  Результаты проверяли авторы;
- подготовить черновики codebook, конфигураций Label Studio и README, настроить Label Studio;
- разобрать расхождения: ИИ предлагал итоговые метки со ссылкой на правила codebook,
  решение принимали аннотаторы.

Разметку — метки SMS, подписи и категории аудио — выполняли аннотаторы вручную.
Протокол общения с ИИ будет приложен к отчёту.

## 8. Ограничения и следующие шаги

- **Объём аудио.** Для Clotho собрано 25 записей. Хотим согласовать объём ручного сбора:
  у audio captioning нет классов, мы ориентируемся на 50 записей.
- **Качество аудио.** Записи Freesound скачаны в виде превью (MP3, ~128 кбит/с), а не оригиналов.
  Исходный Clotho использует оригинальные файлы.
- **Ближайшие шаги:**
  - закончить вторую разметку аудио и посчитать согласие по Clotho;
  - обновить codebook Clotho;
  - перейти к синтетическому обогащению: ≥ 100 % от объёма каждого датасета.
